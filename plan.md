The project is called "My To Do"
I want an application that mimics Microsoft To Do. The application should be a PWA web app that has a basic marketing page with a login button that connects to Google only. 

When logged in, the UI mimics MS ToDo in terms of:

There is a My Day list which shows any To Dos with a Due Date of today.
There is a default Tasks list. This is the main list of tasks.
Below this are custom Lists the user created.
UI to add a list.

Users can create new lists.
Users can create groups of lists.

Each To Do item can have:

A title
A steps list
A due date
A reminder date
A repeat pattern (daily, weekly, monthly, yearly)
A completion status
A note (free form text)

Lists UI:
Shows tasks not marked as complete. Below the list is a "Completed" section that shows completed tasks. It's a collapsed list by default but the user can click to open it. 

Search:
Searches across all to dos.

Implementation:

Alpine.js, vanilla web. 
Hosted on Netlify.
Database via Supabase (use the project To Do)
